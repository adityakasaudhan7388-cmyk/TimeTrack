
# TimeTrack

### Personal Productivity & Study Tracking Dashboard

TimeTrack is a web-based study productivity application designed to help students manage study time, daily tasks, goals, and productivity.

## Features

- Study time tracker
- Daily task management
- Daily study planning
- Weekly study hours graph
- Task progress graph
- Planned vs actual study time
- Daily performance tracking
- Backlog management

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   pip install -r requirements.txt

5. Start the application:

   py app.py

6. Open your browser:

   http://127.0.0.1:5000
